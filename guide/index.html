JSON Formatter — Common Use Cases

Paste a minified JSON response from an API and DevLab formats it with proper indentation and colour coding. If your JSON has a syntax error — a missing comma, unclosed bracket or unquoted key — it shows the exact line and character where the error occurs, making debugging fast.

The JSON ↔ CSV tool is useful when you receive API data as a JSON array and need to open it in Excel or Google Sheets. It flattens the first level of keys into CSV columns.

JWT Decoder

A JWT (JSON Web Token) has three parts separated by dots: header.payload.signature. Each part is Base64URL-encoded. DevLab decodes the header (algorithm used) and payload (claims like user ID, expiry, roles) into readable JSON. It also shows the token's expiry time in a human-readable format. Note: DevLab does not verify the signature — use this for inspection only, not for security decisions.

Frequently Asked Questions

How do I validate JSON online?

Paste your JSON string into the JSON Formatter tool. If valid, it formats and colour-codes it. If invalid, it shows an error at the exact line and character position causing the problem — such as a trailing comma or mismatched bracket.

How do I decode a JWT token?

Paste the full JWT (three base64 segments separated by dots) into the JWT Decoder. DevLab shows the decoded header, payload and expiry time as formatted JSON. The signature is not cryptographically verified — use this for inspection and debugging only.

What is a cron expression?

A cron expression defines a recurring schedule in 5 fields: minutes, hours, day-of-month, month, day-of-week. For example, 0 9 * * 1 means "every Monday at 09:00". The Cron Builder lets you pick the schedule visually and shows the human-readable equivalent.
